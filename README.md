# 📘 FB Clone Website

A **Facebook-inspired social media website clone** created as a learning project while practicing **Git and GitHub**. This project was developed to gain hands-on experience with web development, project organization, and version control using Git.

The main purpose of this project was not to create an exact copy of Facebook, but to understand how a modern social media interface can be structured and how a web development project can be managed using Git.

---

## 🚀 About the Project

The **FB Clone Website** is a front-end project inspired by the design and layout of Facebook. It contains a social-media-style interface where users can explore different sections of a typical social networking website.

I created this project while following a **Git tutorial**, using it as an opportunity to practice Git commands and understand how version control works in a real project.

Through this project, I practiced concepts such as:

* Creating and managing a Git repository
* Tracking changes with Git
* Making commits
* Working with different versions of a project
* Understanding the Git workflow
* Uploading a project to GitHub
* Organizing project files
* Managing changes during development

## 💻 How to Run the Project

To run this project locally, clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/fb-clone-website.git
```

Move into the project directory:

```bash
cd fb-clone-website
```

Then open the main HTML file:

```text
index.html
```

You can open it directly in a web browser or use a development extension such as **Live Server** in Visual Studio Code.
